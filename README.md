# Student Analytics Dashboard

## Project Overview
A data analytics project to analyze student academic performance using Excel, PostgreSQL, and Power BI.

## Tools Used
- Microsoft Excel
- PostgreSQL
- Power BI

## Dataset
Student Performance Dataset – 5,000 Records

## Analysis
- Class-wise performance
- Subject-wise performance
- Attendance analysis
- Pass and fail analysis
- Grade distribution
- Fee status analysis
- Top and bottom performing students

## Dashboard
An interactive Power BI dashboard was created to visualize student performance and identify meaningful insights.

## Project Outcome
This project provided practical experience in data cleaning, SQL analysis, data visualization, and dashboard creation.
